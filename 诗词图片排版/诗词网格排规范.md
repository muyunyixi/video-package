# 诗词网格排规范（v1.1）

> 用户在稿定设计里做的诗词图片（近体诗红底、宋词蓝底），按这份规范用网格排重新出图，输出 1440×1920 PNG。
> 只管这类静态诗词图，与视频无关（见本目录 `README.md`）。
> v1.0 由 Gemini 整理（以原图实测坐标为基准重排）；v1.1 起（2026-10-25）改为“只给内容就能生成”，参考图只用来识别小黄标和对照偏差。修订记录见第十节。

## 一、要点

1. **只给内容就能出图**：标题、副标题、正文、署名、哪几个字下面有小黄标——位置全部由本规范算出，不依赖参考图。
2. **水平**：网格排（一字一格、墨迹居中于字格）；正文最宽的一行在画布上严格居中，它的左格就是全图主左轴 `x0`；标题、横线（宋词是副标题底块）左对齐 `x0`。
3. **纵向**：按稿定设计的文本框叠放（字号 × 行距），整组在画布上垂直居中，再加一个实测校准量。
4. **小黄标**：左右中心对准所标字的字格中轴；同一行的标共用一个高度：墨迹上缘 = 该行基线 + 9.2 px；有字压到标，整行一起下移。
5. **参考图（可选）**：自动识别小黄标在哪些字下面，并逐项列出参考图与标准位置的偏差。

## 二、画布与换算

- 稿定设计的逻辑画布（1x）是 1242×1656（3:4）。字号、行距都按 1x 填。
- 输出 1440×1920。换算倍率 `S = 1440 / 1242 = 80/69`：正文 69 号正好 80 px，1.5 倍行距正好 120 px，没有小数累积。
- 其余字号：主标题 114 → 132.1739 px；横线、署名、宋词副标题 60 → 69.5652 px；近体诗副标题 50 → 57.9710 px。
- 字体只用 `汇文明朝体.otf`（仓库 `公共/` 里那一份；1 em = 1024 单位）。

## 三、排版纪要（稿定设计里的设置）

纵向从上到下叠放；整组垂直居中。

**颜色**：字白色 `#FFFFFF`；小黄标 `#F9C06A`（稿定里字号 36）；宋词副标题底块 `#B2AAD9`（≈ 白色 66% 不透明度叠在蓝底上），底块上的字 `#1E0692`。

## 四、水平：网格排

1. **一字一格**：每个汉字、全角标点（含“—”、引号、书名号、括号）占 1 em 字格（正文 80 px）；半角字（署名里的 `/muyun.`）按字体步进占格。汇文明朝体很多字的步进不是整 1024（“了”915、“，”999、“红”1027……），一律不照它。
2. **字在格里按墨迹居中**：`绘制原点 = 字格左缘 + 字格宽/2 − (xMin + xMax)/2 × 字号/1024`；开符号靠字格右边，闭符号靠左边；署名不做墨迹居中，按步进原样放。同一行共用一条基线。
3. **整行边界一律取字格外缘**：行首行尾是标点也不扣标点那一侧的空白。
   - 这一条和 `公共/字体处理规范.md` 第三节第 5 条（视频里行尾标点按墨迹算边界）**故意不同**，诗词图按这里的。
4. **主左轴**：`x0 = (1440 − 最宽一行字格总宽) / 2`。16 字的行 `x0 = 80.00`，14 字 160.00，12 字 240.00。
5. **各元素**：
   - 正文：近体诗每行左对齐 `x0`，同一列的字上下严格对齐；宋词每行各自居中 `x0_行 = (1440 − 该行字格宽) / 2`（参考图《定风波》如此；字数奇偶不同的行会差半格）。
   - 主标题、横线左对齐 `x0`；近体诗副标题右对齐横线右端；宋词副标题底块左缘在 `x0`。
   - 署名：全部字格总宽在画布中线 720 上居中。
6. 所有字转成 SVG 轮廓路径再栅格化，位置精确到万分之一像素，不受浏览器基线取整影响。

## 五、纵向：文本框叠放

1. **行框与基线**：稿定设计把字体外框（`head` 表 yMin −327 … yMax 901）放在行框里上下居中：
   `行框上缘到基线 = 行距 × 字号 / 2 + β × 字号`，`β = (901 + (−327)) / 2 / 1024 = 0.28027`。
2. **叠放**：按第三节的表从上到下，一个元素的行框高 = 字号 × 行距；正文框高 = (正文行数 + 2) × 103.5（正文各行、空一行、署名行）。总高 `H` 求和后，顶部 `top = (1656 − H) / 2`（1x），逐个累加得到各元素基线，再乘 `S` 换到输出像素。
3. **实测校准**（输出像素，加在算出的基线上）：近体诗全部 +1.33；宋词主标题 0、副标题 +0.6、正文与署名 +1.75。
   - 来源：2026-10-25 的四张参考图。近体诗三张（两首绝句、一首七律）每个元素都比公式低 1.0–1.6 px，而且整体一致，是稿定内部的取整或边距；加上校准后，三张图所有元素的基线偏差都在 ±0.35 px 内。宋词只有一张，样本多了再修。
4. **结果**（输出像素）：
   - 近体诗 2 行：主标题 607.65，横线 673.58，副标题 716.71，正文 916.22 / 1036.22，署名 1276.22。
   - 近体诗 4 行（七律）：整组比 2 行时上下各多出 120 px，主标题 487.65 … 署名 1396.22。
   - 宋词《定风波》（6 行 + 1 空行）：主标题 356.18，副标题 454.01，正文 671.13 起每行 +120，署名 1631.13；副标题底块 y 385.82–475.42。
5. 宋词副标题底块：上缘 = 副标题行框上缘，高 89.6 px；宽 = 副标题字格总宽 + 2 × 9.6。

## 六、小黄标

1. **形状**：`poemgrid/mark_path.py` 里的矢量轮廓（v1.0 的 MARK_SVG_D，按稿定 2x 图描出，字号 36），墨迹约 26.9 × 26.9 px。
2. **水平**：墨迹左右中心 = 所标字的字格中轴（网格排后也就是这个字的墨迹中心）。v1.0 的公式比中轴偏左 0.64 px，v1.1 起改为正中。
3. **纵向**：同一行的标共用一个高度，**墨迹上缘 = 该行基线 + 9.2 px**。
   - 来源：近体诗四张参考图共 5 行、28 个小黄标，同一行的标高度一致，各行平均上缘在基线下 9.04–9.40 px（总平均 9.24），与标在哪个字下、第几行无关。所以它跟着行走，不跟着字的墨迹走。
4. **防撞**：在只有字的图上量每个标正上方、标的宽度范围内那个字的墨迹底边（50% 交点）。任何一个标的上缘高于它（间隙 < 0），这一行的标整体下移，直到间隙最小的那个留出 0.5 px。报告里列出每个标的间隙和是否下移。
5. 配置里用花括号标：`"初拈彩缕{花先老}，春在针尖{不肯开}。"`。没写花括号又给了参考图，就从参考图识别。

## 七、用法

```bash
pip install -r requirements.txt          # Python 3.11 以上
python make_poem.py poems/绝句-春天停下了么.toml
python make_poem.py poems/绝句-春天停下了么.toml --ref 参考图.jpg   # 另出参考图对照
```

- 输出：`output/<配置名>.png`（1440×1920，RGB）和 `output/<配置名>_报告.txt`；`--svg` 另存 SVG，`--zip` 另打 zip。
- 配置（TOML）：`mode`（近体诗 / 宋词）、`title`、`subtitle`、`body`（每行一句；宋词上下阕之间写 `""`）、`sign`。例子在 `poems/`。
- 改模板参数（字号、行距、颜色、校准量、小黄标高度）只改 `poemgrid/template.py`。
- **参考图**：稿定 2x 原图（2484×3312）、重排过的图、聊天软件压缩过的图都可以，必须是完整的 3:4 图（裁过的会被拒绝），统一缩放到 1440×1920 再量。报告的第四节逐项列出：每个元素的基线 Δy、左右墨迹边 Δx、实测字号，宋词副标题底块的偏差，每个小黄标的 Δx（标中心 − 字的墨迹中心）和上缘到基线的距离；超过 1 px 的打“←”。参考图的作用是对照和识别，**出图不跟着参考图走**；如果某张图是故意排得不一样，看报告再决定改配置还是改模板。

## 八、量法与复测

1. **颜色分离**：背景、白字、小黄标三种纯色，用线性解求每个像素里白字和小黄标的覆盖率；抗锯齿边上的混合色也能分开，所以量白字时完全不受小黄标干扰，反过来也一样（红底、蓝底都成立）。宋词副标题在底块色和字色之间求覆盖率。
2. **50% 交点**：每列（或每行）取最大覆盖率，在 0.5 处找首末交点，像素 j 看作 j + 0.5 处的采样，相邻像素之间线性插值，得到亚像素的墨迹边。
3. **基线**：由一行的墨迹上下边和这行字在字体里的最高、最低轮廓反推，两个估计取平均。
4. **导出复测**（每次出图自动做）：在导出的 PNG 上逐字量墨迹中心，与算出的位置比。合格：水平 ±0.5 px 以内（实测全部在 ±0.3 px 内，最大的是署名的半角字母）；小黄标的位置误差在 0.2 px 内。竖直方向只作参考：汇文明朝体笔画边缘毛糙，尖细的末端抗锯齿后会缩进零点几像素。

## 九、待确认

1. **横线的行距**：用户说现在是 1；但四张参考图量出来都是 0.5（行距 1 时横线到主标题、到副标题的基线距离会各多 17.4 px，图上没有）。现在按 0.5 出图；如果稿定模板已经改成 1，把 `template.py` 里 `JINTI["rule"]` 改成 `(60, 1.0)`，并用新图重新校准第五节第 3 条。
2. **宋词小黄标的高度**：《定风波》参考图里标的上缘在基线下 5.2–5.8 px，比近体诗高约 3.6 px，压到了“盈”“手”“唤”“个”的笔画底边。现在统一按 9.2 px 出图（不压字）。
3. **宋词副标题底块**：颜色、左右边距、高度是从一张图量的；稿定里如果有确切的设置（底色、不透明度、内边距），以设置为准。
4. **宋词正文每行居中**：按参考图做；近体诗等长，不受影响。
