# 诗词网格排规范（v1.3）

> 用户在稿定设计里做的诗词图片（近体诗红底、宋词蓝底），按这份规范用网格排出图，输出 1440×1920 PNG。只管这类静态诗词图，与视频无关。
> 仓库：`https://github.com/muyunyixi/video-package`，目录 `诗词图片排版/`。**新窗口先读第〇节。**
> v1.0 由 Gemini 整理（以原图实测坐标为基准重排）；v1.1 起（2026-10-25）改为“只给内容就能生成”，参考图只用来识别小黄标和对照偏差。修订记录见第十节。

## 〇、给新窗口（先读这一节）

### 1. 开工

1. 把仓库 `muyunyixi/video-package` 拉到会话里（用会话里添加 GitHub 仓库的工具，或 `git clone`），进入 `诗词图片排版/`，`pip install -r requirements.txt`（Python 3.11 以上）。字体直接读仓库的 `公共/汇文明朝体.otf`，不用复制。
2. 用户会给两种材料之一：
   - **文字**：体裁（近体诗 / 宋词）、标题、副标题、正文、要加小黄标的字、署名。照 `poems/` 里同体裁的例子写一份 TOML，小黄标用花括号标在字上，例如 `"{小字}听来{低首久}，…"`；宋词上下阕之间写一个空字符串 `""`。
   - **他在稿定里做好的图**：把图上的文字一字不改地抄进配置，图当参考图（`--ref`）；配置里不写花括号时，小黄标从图上自动识别。
3. `python make_poem.py poems/<名字>.toml [--ref 图]`，输出在 `output/`：PNG 发给用户；`_报告.txt` 里的要点用一两句话告诉他（有没有字贴上小黄标、正文偏右是否超过提醒值、参考图纵向偏差大不大）。

### 2. 和用户怎么配合

- 用户多用语音转文字，同音字会转错（例：“墨迹”被转成“末句”）。先把他的话整理成条目、写出自己的理解，拿不准就问。
- 用户对数值要求很严（他自己说有强迫症）：说位置就给在导出图上量出来的数，不说“看起来差不多”。要改规则时，先用几首诗把影响算出来给他看，他确认了再改。
- 用户的意见是建议：对的做，拿不准的讨论，有更好的方案就提出来。
- 一律用中文。

### 3. 约定

- 诗词原文一个字不改（标点也不改）；署名按用户定的写（现在是 `/muyun.`）。
- 版本号写作 v大.小：小优化、小改动，小版本加一（v1.2 → v1.3）；整体或根本性的改动才加大版本（`公共/整体制作指南.md` 第四节；用户 2026-10-25 又特别强调过，不要一下从 v1.0 跳到 v2.0）。
- 改规则：先改本规范（含第十节修订记录），再改代码，出图复测通过后提交推送。
- 提交：首行写成“诗词图片排版：vX.Y 做了什么”，不超过 25 个字；署名 `muyun <19288906+muyunyixi@users.noreply.github.com>`（`git config` 只设在这个仓库）；提交说明里不加 Claude 的署名行（`Co-Authored-By`、`Claude-Session`）。
- 出的图、用户的诗词图都不进仓库，发给用户。
- 本目录与视频无关：做视频的窗口不读这里；这里也不要照 `公共/字体处理规范.md` 去“统一”。两边的网格排和整行边界规则现在是一致的，但纵向排法、小黄标、宋词底块、署名居中是诗词图自己的。

### 4. 用户的原图和本规范的差别（是有意的，不要去“修”规则）

- **水平**：稿定按字格居中，“。”右边的空白也算进行宽，所以原图的正文、标题、横线普遍比本规范偏左约 12 px，署名偏左约 2 px。2026-10-25 用户定按本规范（第四节）。
- 用户以前觉得偏左有好处：抖音右侧有一列按钮会挡字。分析的结论是那列按钮比 12 px 宽得多，偏左 12 px 对遮挡几乎没有帮助；真要避让，应另加一个“整组左移 N px”的参数（署名一起移），图内部的对齐不变。现在没有做，用户没要。
- **纵向和小黄标**：与原图一致（四张参考图偏差在 ±0.35 px 内），参考图主要用来核纵向和识别小黄标。
- 有的原图在稿定里整组位置就偏了（第九节第 2 条）。
- 以后用户可能只发文字和要加小黄标的字，不再发图。

### 5. 自由发挥（用户 2026-10-25 允许）

- 可以在稿定模板之外加一点自己的小巧思，甚至做得比稿定更多。先交一张按本规范的标准版，再另出巧思版，说清楚改了什么、为什么；用户选中了，再商量要不要写进规范。
- 不动的：诗词原文；网格排（一字一格、墨迹居中于字格）；位置在导出图上量过。

## 一、要点

1. **只给内容就能出图**：标题、副标题、正文、署名、哪几个字下面有小黄标——位置全部由本规范算出，不依赖参考图。
2. **水平**：网格排（一字一格、墨迹居中于字格）；正文按“汉字取字格外缘、标点取墨迹”的两端边界在画布中线居中；排好后最宽一行的左格是全图主左轴 `x0`，标题、横线（宋词是副标题底块）左对齐 `x0`；署名按墨迹绝对居中。
3. **纵向**：按稿定设计的文本框叠放（字号 × 行距），整组在画布上垂直居中，再加一个实测校准量。
4. **小黄标**：左右中心对准所标字的字格中轴；墨迹上缘固定在该行基线下 9.4 px，不因个别字贴上而挪动。
5. **参考图（可选）**：自动识别小黄标在哪些字下面，并逐项列出参考图与标准位置的偏差。

## 二、画布与换算

- 稿定设计的逻辑画布（1x）是 1242×1656（3:4）。字号、行距都按 1x 填。
- 输出 1440×1920。换算倍率 `S = 1440 / 1242 = 80/69`：正文 69 号正好 80 px，1.5 倍行距正好 120 px，没有小数累积。
- 其余字号：主标题 114 → 132.1739 px；横线、署名、宋词副标题 60 → 69.5652 px；近体诗副标题 50 → 57.9710 px。
- 字体只用 `汇文明朝体.otf`（仓库 `公共/` 里那一份；1 em = 1024 单位）。

## 四、水平：网格排

1. **一字一格**：每个汉字、全角标点（含“—”、引号、书名号、括号）占 1 em 字格（正文 80 px）；半角字（署名里的 `/muyun.`）按字体步进占格。汇文明朝体很多字的步进不是整 1024（“了”915、“，”999、“红”1027……），一律不照它。
2. **字在格里按墨迹居中**：`绘制原点 = 字格左缘 + 字格宽/2 − (xMin + xMax)/2 × 字号/1024`；开符号靠字格右边，闭符号靠左边；署名里的字按步进原样放。同一行共用一条基线。
3. **整行的两端边界**：行首、行尾是汉字，取字格外缘（把字当占位）；是标点，取标点的墨迹（标点那一侧的空白不算）。与 `公共/字体处理规范.md` 第三节第 5 条相同。
4. **正文怎么放**（按这个顺序）：
   1. 先按网格排好每一行。近体诗各行左端对齐、共用一张网格，同一列的字上下严格对齐。
   2. 再按第 3 条的两端边界，在画布中线 720 上居中：近体诗整块居中（取各行边界的最外侧），宋词每行各自居中。
   3. 主左轴 `x0` = 排好后最宽那一行的左格（字格左缘）。主标题首字字格、横线首格、宋词副标题底块左缘对齐 `x0`；近体诗副标题末字字格右缘对齐横线右端 `x0 + 9 × 69.5652`。
   - 结果：以汉字开头、“。”结尾的行，比按字格居中右移 13.34 px（“。”画在字格正中，右边空 26.68 px，取一半）。16 字的行 `x0 = 93.34`，14 字 173.34，12 字 253.34。
   - 看得见的字会略偏右，偏右量 = 首字左边留白的一半：四首例诗 +0.84 – +3.26 px；随机 3000 个汉字在 80 px 字格里的左留白中位 3.98 px，所以一般偏右约 2 px，九成在 +1.0 – +3.3 px。接受它：句末的“。”是个小空圈，视觉上比汉字轻，人眼感觉的中心本来就在墨迹中点偏左一点；而且左轴不随首字跳动。首字特别窄（如“卜”）时偏右会变大，报告里超过 4 px 提醒。
   - 不用“两端都按墨迹”：左轴会随每首诗的首字变（三首近体诗分别是 91.43、91.88、92.50），宋词字数相同的行同一列会错开约 1 px。
5. **署名**：字照第 2 条排好，整行按墨迹（最左一笔到最右一笔）在 720 上绝对居中。署名首尾可能是斜杠、英文、汉字或标点，按字格居中的偏差随内容变（`/muyun.` −2.27、`/muyun` +1.80、`/慕云` +1.09、`/慕云。` −8.97 px），按墨迹总是 0。
6. 所有字转成 SVG 轮廓路径再栅格化，位置精确到万分之一像素，不受浏览器基线取整影响。

## 五、纵向：文本框叠放

1. **行框与基线**：稿定设计把字体外框（`head` 表 yMin −327 … yMax 901）放在行框里上下居中：
   `行框上缘到基线 = 行距 × 字号 / 2 + β × 字号`，`β = (901 + (−327)) / 2 / 1024 = 0.28027`。
2. **叠放**：按第三节的表从上到下，一个元素的行框高 = 字号 × 行距；正文框高 = (正文行数 + 2) × 103.5（正文各行、空一行、署名行）。总高 `H` 求和后，顶部 `top = (1656 − H) / 2`（1x），逐个累加得到各元素基线，再乘 `S` 换到输出像素。
3. **实测校准**（输出像素，加在算出的基线上）：近体诗全部 +1.33；宋词主标题 0、副标题 +0.6、正文与署名 +1.75。
   - 来源：2026-10-25 的四张参考图。近体诗三张（两首绝句、一首七律）每个元素都比公式低 1.0–1.6 px，而且整体一致，是稿定内部的取整或边距；加上校准后，三张图所有元素的基线偏差都在 ±0.35 px 内。宋词只有一张，样本多了再修。
4. **结果**（输出像素）：
   - 近体诗 2 行：主标题 607.65，横线 673.58，副标题 716.71，正文 916.22 / 1036.22，署名 1276.22。
   - 近体诗 4 行（七律）：整组比 2 行时上下各多出 120 px，主标题 487.65 … 署名 1396.22。
   - 宋词《定风波》（6 行 + 1 空行）：主标题 356.18，副标题 454.01，正文 671.13 起每行 +120，署名 1631.13；副标题底块 x 93.34–739.14，y 385.46–474.73。
5. **宋词副标题底块**：稿定按字自动加的，设置里没有可调的边距。实测它就是字的内容框四周各加一圈边距：
   - 内容框：宽 = 副标题字格总宽；高 = 字体 hhea 的上下界（864 / −160，正好 1 em = 字号），即基线上 0.84375 × 字号到基线下 0.15625 × 字号。
   - 边距 8.5（1x）= 9.855 px：《定风波》量出的四边是上 8.29、下 9.00、左右各 8.36，平均正好 8.50；按 8.5 画，四边与参考图的偏差都在 0.6 px 内。
   - 所以底块 `x = x0`，`y = 副标题基线 − 0.84375 × 69.5652 − 9.855`，宽 = 字格总宽 + 2 × 9.855，高 = 69.5652 + 2 × 9.855 = 89.28 px；字从 `x0 + 9.855` 起排。

## 六、小黄标

1. **形状**：`poemgrid/mark_path.py` 里的矢量轮廓（v1.0 的 MARK_SVG_D，按稿定 2x 图描出，字号 36），墨迹约 26.9 × 26.9 px。
2. **水平**：墨迹左右中心 = 所标字的字格中轴（网格排后也就是这个字的墨迹中心），跟着字走。
3. **纵向**：**墨迹上缘 = 所在行基线 + 9.4 px，固定不动**（宋词、近体诗一样），所以同一行的标一样高，每一行的标离自己那行的距离也一样。
   - 来源：近体诗四张参考图共 5 行、28 个小黄标，同一行的标高度一致，各行平均上缘在基线下 9.04–9.40 px，与标在哪个字下、第几行无关——它跟着行走，不跟着字的墨迹走。用户 2026-10-25 定取 9.4：大多数字和标略微分开，偶尔贴上可以接受。
   - 不因个别字的底边贴上而挪标（挪了的话，每次挪的行、挪的量都不一样）。
4. **间隙报告**：在只有字的图上量每个标正上方、标的宽度范围内那个字的墨迹底边（50% 交点），报告每个标的间隙；负数（贴上）注“贴上”，压进去超过 2 px 的打“←”提醒。只报告，不挪。
   - 四首例诗 28 个标：26 个分开（间隙 +0.56 – +24.11 px），2 个贴上：“却”−1.22 px、“字”−0.22 px。
5. 配置里用花括号标：`"初拈彩缕{花先老}，春在针尖{不肯开}。"`。没写花括号又给了参考图，就从参考图识别。

## 七、用法

```bash
cd 诗词图片排版
pip install -r requirements.txt          # Python 3.11 以上
python make_poem.py poems/绝句-春天停下了么.toml
python make_poem.py poems/绝句-春天停下了么.toml --ref 参考图.jpg   # 另出参考图对照
```

- 输出：`output/<配置名>.png`（1440×1920，RGB）和 `output/<配置名>_报告.txt`；`--svg` 另存 SVG，`--zip` 另打 zip。
- 配置（TOML）：`mode`（近体诗 / 宋词）、`title`、`subtitle`、`body`（每行一句；宋词上下阕之间写 `""`）、`sign`。例子在 `poems/`。
- 改模板参数（字号、行距、颜色、校准量、小黄标高度）只改 `poemgrid/template.py`。
- **参考图**：稿定 2x 原图（2484×3312）、重排过的图、聊天软件压缩过的图都可以，必须是完整的 3:4 图（裁过的会被拒绝），统一缩放到 1440×1920 再量。报告第四节逐项列出：每个元素的基线 Δy、左右墨迹边 Δx、实测字号，宋词副标题底块的偏差，每个小黄标的 Δx（标中心 − 字的墨迹中心）和上缘到基线的距离；超过 1 px 的打“←”。
  - 稿定排的图水平方向普遍是 −12 px 左右、署名 −2 px 左右（第〇节第 4 条），属正常；主要看纵向 Δy 和小黄标。
  - 参考图的作用是对照和识别，**出图不跟着参考图走**；某张图如果是故意排得不一样，看报告再决定改配置还是改模板。

## 八、量法与复测

1. **颜色分离**：背景、白字、小黄标三种纯色，用线性解求每个像素里白字和小黄标的覆盖率；抗锯齿边上的混合色也能分开，所以量白字时完全不受小黄标干扰，反过来也一样（红底、蓝底都成立）。宋词副标题在底块色和字色之间求覆盖率；底块本身的四边用“白的覆盖率 ÷ 0.66”的 50% 交点量（每行、每列取中位数做剖面，避开底块上的字和上方的主标题）。
2. **50% 交点**：每列（或每行）取最大覆盖率，在 0.5 处找首末交点，像素 j 看作 j + 0.5 处的采样，相邻像素之间线性插值，得到亚像素的墨迹边。
3. **基线**：由一行的墨迹上下边和这行字在字体里的最高、最低轮廓反推，两个估计取平均。
4. **导出复测**（每次出图自动做）：在导出的 PNG 上逐字量墨迹中心，与算出的位置比。合格：水平 ±0.5 px 以内（实测全部在 ±0.35 px 内，最大的是署名的半角字母）；小黄标的位置误差在 0.1 px 内。竖直方向只作参考：汇文明朝体笔画边缘毛糙，尖细的末端抗锯齿后会缩进零点几像素。

## 九、待确认、已知情况

1. **宋词**：校准量（第五节第 3 条）、底块边距 8.5、正文每行居中，都只来自《定风波》一张图；有新的宋词图时用 `--ref` 对照一下，纵向偏差大于 1 px 再修。
2. **稿定里的“居中”不一定等于看得见的字居中**：2026-10-25 第二张《绝句·春天停下了么》（JPG）和第一张（PNG）文字完全相同，却整组向左偏了约 12.6 px——主标题 −12.1、横线 −12.6、正文第二行 −12.6，连没有中文标点的署名也 −12.6（另外三张图署名中心都在 720.0–720.2）；整图互相关也是 −13 px。同样的字、同样的标点，排出来的宽度不会变，所以不是标点空白算没算的问题，是整组在画布上的位置。用户在稿定里看是居中的；可能是被居中的选区里含了看不见的文本框（空文本框、底部透明文本框）往右伸得更远，或者软件本身的问题。本工具按内容算位置，不受影响；拿这类图做参考图时，报告里整组的 Δx 会一起再偏。
