# 诗词排版视觉插件说明包（v2.6）

> 本文件是《`诗词网格排规范.md`（v2.6）》的**独立可选插件说明包**，对应代码模块 `poemgrid/plugins.py`。
> 背景底色全系列统一固定为纯粹实色朱红 **`#900202`**（近体诗/古风与宋词同底），不做任何渐变或噪点。
> **体裁分工规范（v2.2）**：宋词默认仅启用右上角 `40%` 瘦竹新月角标（大字藏锋默认关闭，仅极短篇按需选配），标注配合 `[...]` 金句变黄与 `<...>` 短句选中框；律诗/古风偏庄重严肃，**不启用**插件一与 `<...>` 整句选中框，精妙字词统一使用 `{...}` 小黄标（句逗）。
> 日常只排标准稿定版时无需启用本文件；当需要对背景做古籍装帧异化，或对正文次重点句做选中底色强调时，按需引用以下**两个插件**即可。

## 一、两大插件总览与配置速查

1. **插件一：背景装帧异化插件（二合一共同使用）**——在纯粹实色底上，**同时叠加「大字藏锋」右下角对称底字暗纹 + 右上角固定 `40×140 px` 纯装饰角标（默认瘦竹新月 `bamboo_moon`）**共同使用。
2. **插件二：正文选中底衬插件（`<...>` 浅金底衬 + 底边虚线）**——用于在正文中给不想改黄字、也不想连排小黄标的次重点句添加 `18.0%` 浅金选中背景与 `70.0%` 底沿暖金虚线。

| 插件编号 | 插件名称 | 包含模块 / 触发方式 | 核心作用 |
| --- | --- | --- | --- |
| **插件一** | **背景装帧异化插件**（二合一共同使用） | `[plugins]` 下同时配置：<br>1. `watermark = "春"`（大字藏锋）<br>2. `ornament = "bamboo_moon"`（右上角固定角标） | 在纯粹实色底上叠加“右下角 `1080 px`（`4.0%`）端正对称底字暗纹 + 右上角固定 `40×140 px`（`40.0%`）瘦竹新月直角角标” |
| **插件二** | **正文选中底衬插件** | 正文字符串内加尖括号 `<...>` | 对宋词中写得极妙的单独短句添加 `18.0%` 暖金圆角选中底衬与 `70.0%` 底沿暖金虚线（置于白字下方，白字保持纯白锐利） |

## 二、插件一：背景装帧异化插件（二合一：对称底字 + 右上角固定角标）

### 1. 子模块 A：「大字藏锋」—— 右下角超大尺度对称底字暗纹（`watermark`）

- **选字与摆放硬性约束（必守）**：
  1. **同源字体**：严格使用仓库《汇文明朝体》（`公共/汇文明朝体.otf`）矢量轮廓。
  2. **严禁使用倾斜向上的字，必须选用端正对称字**：如「春」「花」「秋」等左右平衡、横画平正字（禁用如「沙」等向右上倾斜字）。
  3. **严禁旋转斜切**：必须 **`0°` 水平端正摆放**。
- **精确数值与坐标（`poemgrid/plugins.py` -> `WATERMARK`）**：
  - **字号**：**`size = 1080.00 px`**（占输出画布宽度 `1440 px` 的 **`75%`**）；颜色 `#FFFFFF`，不透明度 **`4.0%`（`0.040`）**。
  - **定位基准**：墨迹右缘距画布右边界固定留白 **`8.99 px`**（`ink_right = 1431.01 px`），墨迹下缘距画布底边界固定留白 **`70.75 px`**（`ink_bot = 1849.25 px`）。以「春」字为例，绘制原点为 `x = 390.00 px, baseline = 1748.00 px`。

### 2. 子模块 B：右上角固定尺寸纯装饰角标槽位（`ornament`）

- **统一槽位规范（v2.2 固定标准，后续更换任意装饰图案均严守此槽位）**：
  - **固定尺寸**：**宽 `40.00 px` × 高 `140.00 px`**。
  - **固定位置（三边等距 `x0 = 93.34 px` 锚定）**：
    - 槽位右缘对齐主右轴 **`x_right = 1440.00 − x0 = 1346.66 px`**（左缘 `1306.66 px`）；
    - 槽位顶缘对齐上留白 **`y_top = x0 = 93.34 px`**（底缘 **`233.34 px`**）；
    - 全系列诗词（无论 2 行绝句还是 10 行长调，正文首行最高到 `393.6 px`）均在底缘 `233.34 px` 下方留有至少 `160 px` 安全净空，**永远不会撞字且全系列视觉尺寸 100% 统一**。
  - **固定配色与透明度**：暖金 **`#F9C06A`**，统一不透明度 **`40.0%`（`0.400`）**（适配 `#900202` 红底）。
- **默认纹样精确坐标（`ornament = "bamboo_moon"`，瘦竹新月）**：
  为确保后续每次出图**像素级一致**，全部矢量路径均直接固化在 `poemgrid/plugins.py` -> `build_ornament()` 中（锚定 `xr = 1346.6602 px`、`xl = 1306.6602 px`、`yt = 93.3398 px`、`yb = 233.3398 px`）：
  1. **外框 `L` 形角标**：`1.00 px` 线宽，`M (xl, yt) -> L (xr, yt) -> L (xr, yb)`；
  2. **三节微斜瘦竹竿**：起于 `(xr - 11.0, yt + 22.0)`，逐节向左下微偏 `1.5 px`（共斜移 `4.5 px`，形成 `~2.4°` 生机微倾），至 `(xr - 15.5, yb - 10.0)` 止，`1.20 px` 圆头路径；竹节横刻于 `yt + 63.5` 与 `yt + 105.5`；
  3. **偏心双弧透视弦月**：位于 `(xl + 12.9, yt + 22.0)`，外弧半径 `8.50 px`、内弧半径 `7.20 px`（内弧圆心向右上偏移 `(+3.8, -2.2) px`），形成带有侧视透视感的非对称月梢切角；
  4. **两片竹节尖叶**：分别自两道竹节向左下方斜出舒展（叶尖至 `bx - 28.0, yt + 78.0` 与 `bx - 26.0, yt + 123.0`）。
- **备选内置纹样（`ornament = "willow"`，细长柳枝）**：同一 `40×140 px` 槽位内亦固化了修长柳枝与 `4` 片柳叶矢量路径，配置中写 `ornament = "willow"` 即可切换。

## 三、插件二：正文选中底衬插件（`<...>` 18% 浅金底衬 + 70% 底边虚线，`line_box`）

- **图层与颜色**：置于正文白字图层正下方（白字保持 `#FFFFFF` 纯白锐利）；底衬颜色 `#F9C06A`、**不透明度 `18.0%`（`0.180`）**，圆角半径 **`rx = 4.0 px`**。
- **左右边界**：复用宋词副标题底块的左右外扩边距 `pad_x_1x = 8.5`（输出图 `9.8551 px`），左缘 = 括入首字字格左缘 − `9.8551 px`，右缘 = 括入末字有效右边界 + `9.8551 px`。
- **上下边界**：在正文 `1 em` 内容框（`80.00 px`）上下各外扩 `pad_y_px = 6.00 px`（总高 **`92.00 px`**）。
- **底边虚线**：沿底衬下沿绘制 `#F9C06A` 暖金虚线，**不透明度 `70.0%`（`0.700`）**，线宽 **`1.60 px`**，步进 **`5 5`**。
