# video-package

用代码生成的诗词短片的备份：每部片子的代码包和文档，以及所有片子共用的规范和字体。

## 目录

| 目录 | 内容 |
|---|---|
| `CLAUDE.md` | 新窗口接手说明：先读什么、新片怎么建、工作规则速查、能直接用的代码 |
| `公共/` | 共用的三份规范、字体、新片的文档模板（见 `公共/README.md`） |
| `字与心事/` | 《字与心事》的代码包（解开存放）：源码、渲染与混音脚本、封面、排字与测量工具；`docs/` 里是这部片子的项目文档、版本迭代与需求变更记录、诗词稿件。说明见 `字与心事/README.md` |
| `诗词图片排版/` | **与视频无关**：稿定设计诗词图片（红底近体诗、蓝底宋词）的网格排规范和出图工具，只借用 `公共/` 的字体。做视频时不用读，说明见 `诗词图片排版/README.md` |

## 约定

- 每发一个版本（版本号变了）提交、推送一次，一次提交大体就是一个版本；预览、草图不单独推送。
- 提交说明的首行写成“<片名或公共>：vX.Y 做了什么”，不超过 25 个字，细节写在空一行之后的正文里。GitHub 文件列表里每个文件后面显示的，是最近一次改到它的那次提交的首行。
- 提交署名 muyun（GitHub 的隐私邮箱）。
- 每份文件只放一处：共用的规范只在 `公共/`，片子的文件夹里不放副本。
- 不放进仓库：成片视频、封面图、渲染出的帧（成片和封面发给用户，由用户自己保存，claude.ai 的项目里也不放）。
- 代码包不带字体：渲染前把 `公共/汇文明朝体.otf` 复制到 `<片名>/assets/huiwen.otf`。
