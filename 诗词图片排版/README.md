# 诗词图片排版（v2.10）

按《`诗词网格排规范.md`（v2.10）》将诗词内容排成 **1440×1920 PNG**（近体诗/古风与宋词统一采用纯正朱红底 `#900202`，规避抖音客户端蓝通道屏显盲水印）。
两类体裁通过**标题结构 + 标注方式 + 视觉插件**形成明确视觉区分：
- **宋词**：统一「书签条」副标题（`12%` 轻透白底 + `100%` 暖金左竖杠 + `100%` 白字）+ 上下阕留白 + 标注仅用 `[...]` 金句变黄 + 右上角 `40×140 px` `40%` 瘦竹新月角标。
- **近体诗 / 古风**：统一「书签条」副标题（同宋词，`1.8U` 间距）+ 底部预留 `1.0U` 上提防下坠 + 不启用右上角角标，针对精妙字词加 `{...}` 小黄标（句逗）。（注：大字藏锋、水印词序与 `<...>` 选中底衬已于 v2.7 封存停用，代码保留在 `plugins.py` 不默认调用。）

非固定使用的可选视觉扩展能力详见《`视觉插件说明.md`》与 `poemgrid/plugins.py`。

## 快速使用

```bash
pip install -r requirements.txt
# 1. 近体诗 / 古风标准版（不启用插件一，字词高亮用 {...} 小黄标）
python make_poem.py poems/绝句-春天停下了么.toml

# 2. 宋词完整装帧版（见 poems/浣溪沙-种花人立落花中.toml）
python make_poem.py poems/浣溪沙-种花人立落花中.toml --zip
```

## 目录结构

- `诗词网格排规范.md`：v2.10 基础网格排核心规范（必用底座；统一 1U=120px 纵向网格与 60 号副标题）
- `视觉插件说明.md`：v2.10 配套独立视觉插件说明包（宋词装帧与选中框按需引用）
- `make_poem.py`：命令行入口（生成 PNG、SVG、ZIP 与复测报告）
- `poemgrid/`
  - `template.py`：基础模板固定参数（统一红底 `#900202`，近体诗、宋词、小黄标）
  - `plugins.py`：可选视觉插件参数与构建逻辑（`watermark`、`ornament`、`marginalia`、`line_box`）
  - `layout.py`：网格排水平与纵向坐标推算
  - `render.py`：SVG 轮廓路径生成与栅格化（支持 `resvg_py` 与 `pycairo`）
  - `measure.py`：50% 覆盖率交点法导出复测与参考图对照
  - `check.py`：副标题（封面腰封）、标点、平台标题与正文高亮防重复规范检查（v2.10）
  - `glyphs.py` / `mark_path.py`：字体轮廓读取与小黄标矢量路径
- `poems/`：示例 TOML 配置
