# 公共

所有视频共用的规范、字体和新片的文档模板。这里的文件与 claude.ai 项目「视频生成」的根目录是同一批：改了一处，另一处跟着改。新窗口先读仓库根目录的 `CLAUDE.md`（接手说明）。

| 文件 | 内容 | 什么时候读 |
|---|---|---|
| `整体制作指南.md` | 协作方式、版本号、交付、技术方案、通用制作规则、文档维护 | 接手时读第三、四、五、九节，其余用到再查 |
| `文案撰写指南.md` | 发布文案（A 章）、封面（B–D 章） | 定文案、做封面时 |
| `字体处理规范.md` | 字体、网格排、字形尺寸、量法、图片里的字怎么重排 | 排中文之前 |
| `汇文明朝体.otf` | 片名、诗句、封面用的字体（字体文件自己写着 Public Domain） | 渲染前复制到 `<片名>/assets/huiwen.otf` |
| `模板/` | 新片的《项目文档》《版本迭代与需求变更记录》空模板 | 建新片时 |
