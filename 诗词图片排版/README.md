# 诗词图片排版

**这个目录和视频无关。** 做视频（《字与心事》或以后的片子）时不用读、不用改这里的任何文件，也不要把这里的规则搬进视频的规范。

## 做什么

用户在稿定设计里做诗词图片（近体诗红底、宋词蓝底，竖版 3:4），发到抖音等平台。这里是这类图的排版规范和出图工具：给出诗词内容（标题、副标题、正文、署名、哪几个字下面有小黄标），按稿定模板的参数和网格排，生成 1440×1920 的 PNG；也可以拿用户做好的图来对照，列出每个元素偏了多少。

它只放在这个仓库里，是因为不想为几份文件单独建一个仓库。和视频共用的只有字体 `公共/汇文明朝体.otf`（直接读那一份，不复制）。

## 和 `公共/字体处理规范.md` 的关系

两边都用网格排（一字一格、墨迹居中于字格），但这里有几处是诗词图专门定的，**以本目录的规范为准，不要按视频的规范去“统一”**：

- 行首行尾是标点时，整行边界仍取字格外缘（视频里按标点的墨迹算）；
- 纵向位置按稿定设计的文本框叠放推算（第五节），不是视频里的 1.35 倍行距；
- 小黄标、宋词副标题的高亮底块，视频里没有。

## 目录

| 文件 | 内容 |
|---|---|
| `诗词网格排规范.md` | 规范 v1.1：画布与换算、稿定排版纪要、水平与纵向规则、小黄标、用法、量法、待确认事项、修订记录 |
| `make_poem.py` | 出图入口（用法写在文件开头） |
| `poemgrid/template.py` | 模板参数：字号、行距、颜色、校准量、小黄标高度。改模板只改这里 |
| `poemgrid/layout.py` | 算位置（网格排、文本框叠放、小黄标） |
| `poemgrid/render.py` | 出 SVG（字转轮廓）并栅格化成 PNG |
| `poemgrid/measure.py` | 在图上量：小黄标防撞、导出复测、参考图对照 |
| `poemgrid/mark_path.py` | 小黄标的矢量轮廓 |
| `poems/*.toml` | 每首诗一个配置（2026-10-25 的四首作例子） |

## 怎么用

```bash
cd 诗词图片排版
pip install -r requirements.txt                       # Python 3.11 以上
python make_poem.py poems/七律-仲秋客中.toml            # 出图 + 报告，放在 output/
python make_poem.py poems/七律-仲秋客中.toml --ref 图.jpg  # 另和用户的图对照
```

新的一首：复制 `poems/` 里同体裁的一份，改文字；小黄标用花括号标在字上，例如 `"{小字}听来{低首久}，…"`。

## 约定

- 出的图（`output/`）不进仓库，发给用户。
- 用户的诗词图也不进仓库。
- 改了规则：先改 `诗词网格排规范.md`，再改代码，在规范的修订记录里写一条。
