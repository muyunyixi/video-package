# video-package

视频生成项目的备份。目录与项目的划分一致：每个视频一个文件夹，里面是它的代码包；`公共/` 放项目根目录的文件——所有视频共用的规范和字体。

| 目录 | 内容 |
|---|---|
| `公共/` | 《整体制作指南》《文案撰写指南》《字体处理规范》（每次更新都同步到这里），`汇文明朝体.otf`（片名、诗句、封面用的字体，公有领域） |
| `字与心事/` | 《字与心事》的代码包，当前是 v4.5（74.3 秒，2230 帧）：源码、渲染与混音脚本、封面、排字工具、检查脚本，`docs/` 里有项目文档、版本迭代与需求变更记录、桃子诗词稿件，以及打包时三份通用规范的副本。说明见 `字与心事/README.md` |

- 每个代码包解开存放，在 GitHub 上能直接看每个文件、比较两版的差别；各版本用标签区分（如 `字与心事-v4.5`）。
- 代码包不带字体文件：渲染前把 `公共/汇文明朝体.otf` 复制到 `字与心事/assets/huiwen.otf`。
- 成片视频和渲染出的帧不放在这里。
